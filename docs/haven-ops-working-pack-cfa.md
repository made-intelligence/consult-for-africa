## How to use this

The handbook tells you to keep one page of numbers, run a fixed agenda, write a board note and record what you find. These are those pages. Print them, fill them in by hand, and only move them onto a screen once the habit is established, because a form you fill in yourself is a form you read.

Nothing here is clever. The value is entirely in the repetition.
